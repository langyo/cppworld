# 军械库 · 初识标准库

到现在为止，你写的 C++ 程序里几乎每一行都在用标准库——```cout```、```cin```、```string```、```vector```——只是它们来得太自然，你也许没意识到它们已经打了好几回助攻了。

C++ 标准库不是语言语法的附属品，而是跟语法地位同等的半边天。不会用它，等于只会用半门语言。

------

标准库里都有些啥？粗略地分，大致有这么几大类：负责与外界交流的**输入输出**，提供 ```cin```、```cout```、```cerr```、文件流、字符串流；处理文本的**字符串**，也就是比 ```char[]``` 安全十倍的 ```string```；装东西的**容器**，```vector```、```map```、```set```、```list``` 之类；还有人家给你写好的**算法**——排序、查找、计数、最值；**数学**方面有绝对值、三角函数、对数、平方根；**日期时间**有精度到纳秒的 ```chrono```；**内存管理**有 ```unique_ptr```、```shared_ptr```，再也不要手写 ```delete```；**线程**有 ```thread```，让程序一心多用；C++17 起还有跨平台的**文件系统** ```filesystem``` 与处理字符串模式匹配的**正则表达式** ```regex```。

初次看到这张清单可能有点眼花，但别被唬住。每一样都是独立的，用到时进相应的头文件引进来就行。

------

你已经不自觉地用过标准库了：

```cpp
#include <iostream>       // 输入输出库
#include <string>         // 字符串库

int main()
{
    cout << "输入你的名字: ";
    string name;
    cin >> name;
    cout << "你好，" << name << "！\n";
}
```

三行代码里用了两个标准库——```<iostream>``` 提供了 ```cin```/```cout```，```<string>``` 提供了 ```string```。实际上标准库大约 80% 的内容都是在类似层级上提供成熟、安全、零开销的常用能力——你只管引对应的头文件，拿起来就用。

------

C++ 没有"一口吞全库"的头文件。你要用 ```vector```，就引 ```<vector>```；要用 ```sort```，就引 ```<algorithm>```。这种模块化设计的代价是你需要记住常用的头文件名字，好处是不引入你用不到的功能，编译更快。

常用的头文件就那些：```<iostream>``` 提供 ```cin```、```cout```、```cerr```；```<string>``` 提供 ```string```；```<vector>``` 提供 ```vector```；```<map>``` 提供 ```map```；```<set>``` 提供 ```set```；```<algorithm>``` 提供 ```sort```、```find```、```count```、```max```、```min```；```<cmath>``` 提供 ```sqrt```、```abs```、```sin```、```log```；```<memory>``` 提供 ```unique_ptr```、```shared_ptr```、```make_shared```；```<fstream>``` 提供 ```ifstream```、```ofstream``` 用于文件读写；```<sstream>``` 提供 ```istringstream```、```ostringstream```，把字符串当流操作；```<random>``` 提供 ```mt19937``` 引擎与 ```uniform_int_distribution``` 等；```<chrono>``` 提供时间与计时；```<regex>``` 提供正则表达式；```<thread>``` 提供多线程；C++17 的 ```<filesystem>``` 提供目录遍历、文件复制等。

用不着一次全记住，用到哪个查哪个，写多了自然就熟了。

------

标准库的一切都塞在 ```std``` 命名空间里。写 ```std::cout``` 是因为 ```cout``` 不是全局名字，需要走进 ```std``` 领地才能找到。

一行 ```using namespace std;``` 可以把 ```std``` 的全部门对当前作用域敞开。在随手写的小代码中用无妨——但大型项目和头文件中**千万别写**，会把整个全局命名区搞污染，导致你定义的变量跟数百个标准库名字撞车。

折中方案是用 ```using``` 声明只把你真正频繁使用的那几个名字释放出来：

```cpp
using std::cout;
using std::cin;
using std::string;
using std::vector;
```

这样你能写短名字的地方只有这四个，别的一律用 ```std::```——既省了前缀，又不会无意命名冲突。
